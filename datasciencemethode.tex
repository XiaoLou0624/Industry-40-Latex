\section{数据科学方法}

\subsection{木材分拣问题}

一家锯木厂希望将混杂在一起的白蜡木（Esche）与桦木（Birke）板按树种分拣开来，如图 \ref{fig:wood} 所示。整套技术方案由三个环节组成：摄像头依次拍下每一块木板的图像，特征提取环节把图像信息压缩为若干具有区分度的数值特征，分类环节再根据这些特征做出判断，最终输出"白蜡木"或"桦木"的决策。用符号表示，这个过程是从图像空间 $\mathbb{R}^m \times \mathbb{R}^n \times \cdots$，经特征提取映射到特征空间 $\mathbb{R}^d$，再经分类映射到类别集合 $\{Ash, Birch\}$。

\begin{figure}[htbp]
  \centering
  \includegraphics[width=0.5\textwidth]{wood.png}
  \caption{白蜡木与桦木}
  \label{fig:wood}
\end{figure}

最朴素的做法是凭经验假设白蜡木的颜色比桦木更深，于是用图像的平均亮度 $x$ 作为唯一特征，选定一个阈值 $x_S$，亮度超过阈值就判为桦木，反之判为白蜡木。阈值本身由少量样本图像估计得出。用真实样本画出的亮度直方图 \ref{fig:woodhistogram} 确实印证了白蜡木更暗这一经验，但两类样本的亮度分布存在明显重叠，单靠一个亮度阈值无法稳健地区分两种木材。

\begin{figure}[htbp]
  \centering
  \includegraphics[width=0.5\textwidth]{woodhistogram.png}
  \caption{两种木头的亮度直方图}
  \label{fig:woodhistogram}
\end{figure}

于是很自然地想到引入第二个特征：用频谱分析衡量木纹的强弱程度，记作 $x_2$，与亮度 $x_1$ 一起构成二维特征向量 $\mathbf{x} = (x_1, x_2)^t$。把带标签的样本画在这个二维特征空间中，如图 \ref{fig:wood2d}，可以看到两类样本此时已经能被一条直线（记作 $AB$，即决策边界）较好地分开。但随之而来的问题是：这条边界对新样本是否依然有效？它又该如何通过训练自动获得，而不是靠人眼观察画出来？

\begin{figure}[htbp]
  \centering
  \includegraphics[width=0.5\textwidth]{wood2d.png}
  \caption{二维特征空间}
  \label{fig:wood2d}
\end{figure}

这个例子体现了模式分类要处理的核心矛盾：选择怎样的特征、采用怎样的模型、以及如何用有限的样本训练出一个能够推广到未见样本的决策规则。

\subsection{总体设计流程}

围绕上述问题，可以归纳出一套通用的设计循环：采集数据、选择特征、选择模型、训练、评估。评估结果反过来指导对特征、模型乃至数据采集的调整，如此循环，直至性能满足要求。

样本集合通常被划分为三部分：
\begin{itemize}
    \item \textbf{训练样本}用于直接训练分类器
    \item \textbf{验证样本}用于决定何时停止训练
    \item \textbf{测试样本}用于最终评估分类器的性能
\end{itemize}
把全部训练样本完整地送入一次称为一个周期（epoch）。

分类误差随训练过程的变化可以用学习曲线来观察：训练集上的平均误差 $E$ 会逐渐逼近某个最小值 $E_{\min}$，这个最小值取决于贝叶斯误差本身、训练数据量以及分类器 $C_p(x)$ 的表达能力。分类器 $C_p(\mathbf{x}_i)$ 对样本 $\mathbf{x}_i$ 给出类别 $c_i = C_p(\mathbf{x}_i)$，而学习或训练过程 $L(\cdot)$ 的作用是确定分类器的参数 $p$。

根据训练时是否提供、以及如何提供正确答案，学习方式可分为三类：
\begin{itemize}
    \item \textbf{监督学习（Supervised learning）}依据每个样本给定的期望类别 $c_i^*$ 对学到的参数 $p$ 进行修正
    \item \textbf{强化学习（Reinforcement learning）}只依据一个二值的奖惩信号 $r \in \{0,1\}$ 来修正参数，而不直接给出正确类别
    \item \textbf{无监督学习（Unsupervised learning）}则完全不依赖任何期望类别的修正信号
\end{itemize}
