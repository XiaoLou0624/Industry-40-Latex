\section{模拟与编程}

\subsection{数字孪生}

数字孪生（Digitaler Zwilling）的基本设想是为物理世界中的每一项\textbf{资产}都建立一份与之相对应、并在其整个生命周期内持续维护的数字化表征，使得原本只能在实物上进行的操作能够转移到数字侧。

数字孪生并不以完整复刻物理实体为目标。按照定义，数字孪生是\textbf{一种详尽程度足以满足一组既定应用场景之需求的数字化表征}，其边界并非由物理实体本身划定，而是由使用目的反向确定。这意味着同一项资产在不同用途下可以对应不同的孪生。

与之相对，数字影子（Digitaler Schatten）指\textbf{足够精确地反映生产、开发及相邻领域中各类过程的映像}，其目的在于为一切相关数据建立一个\textbf{具备实时处理能力的评估基础}，具体包括对必要数据格式、数据选择及数据粒度层级的描述。

数字影子侧重于由物理侧向数字侧的采集与呈现，构成的是一个\textbf{观测与评估}的基础。

数字孪生要求与其物理对应物之间保持\textbf{双向的数据关联}，数字侧得出的结论能够反作用于物理侧的运行与决策。

若数字孪生的发展延续既有轨迹，未来它很可能\textbf{与管理壳（Verwaltungsschale）这一概念趋同}，而在工业4.0的语境中，管理壳这一术语正逐渐成为优先使用的说法。

\subsection{仿真}

仿真（Simulation）是指在模型中模拟系统行为，以获得可迁移到现实中去的认知。

这个定义中有三个要点值得单独强调。
\begin{enumerate}
  \item 仿真的对象是动态过程，静态的计算不构成仿真。
  \item 模型必须是可实验的，即能够被反复施加不同的输入与参数并观察其响应。
  \item 仿真的目的不在模型本身，而在于取得能够迁移回现实的结论。
\end{enumerate}

在从模型走向可用结论的过程中，还需要区分两个容易混淆的概念：
\begin{itemize}
  \item \textbf{验证（Verifikation）}:检查系统或模型是否满足技术要求。
  \item \textbf{确认（Validierung）}:检查系统或模型是否达成了使用目的。
\end{itemize}

就今天的生产技术而言，仿真技术的典型应用可以按所考察的对象分为四类，每一类各有其相适配的方法（图 \ref{fig:simulationcatagory}）：
\begin{itemize}
  \item \textbf{物流系统}：关注物料流与订单流的时序、排队与产能瓶颈，通常采用\textbf{事件离散仿真}；
  \item \textbf{生产系统}：关注设备布局、可达性与工位之间的配合，通常采用\textbf{三维仿真}与三维可视化；
  \item \textbf{复杂机电系统}：关注多个刚体在关节耦合下的动态行为，通常采用\textbf{多体动力学}；
  \item \textbf{物理参数}：关注连续体内部的变形、应力与温度分布，通常采用\textbf{有限元方法}。
\end{itemize}
四者的差别本质上在于抽象层次的高低：从只关心事件发生的先后顺序，到关心几何与运动，再到关心力与力矩，直至关心材料内部的连续场分布。

\paragraph{面向机器人领域的专业仿真方法}

机器人及相关机电系统的仿真主要依托三种方法：运动学、刚体动力学与有限元方法。三者构成一个逐级深入的序列：从能怎么动，到受力之后怎么动，再到物体内部发生了什么。

\textbf{运动学（Kinematik）}是关于点与刚体运动状态的几何与解析描述的理论，它不考虑作为运动成因的力与力矩，只借助适当的坐标来刻画运动。

\textbf{刚体动力学（Starrkörperdynamik）}研究质点、质点系、刚体在\textbf{所受力与力矩作用下}的运动。其理论基础是能量守恒与动量守恒定律。刚体之间的耦合或接触会产生约束条件，把这些约束纳入之后，即得到整个系统的运动方程。

\textbf{有限元方法（FEM）}是求解偏微分方程的一种数值方法。它的特点是在时间之外还对空间进行离散：将连续体划分为由节点相连的有限个小单元所构成的网格，由此得到一个规模通常很大的方程组，再求解。其基本原理可以浓缩为一个矩阵关系式：
\begin{equation}
  \boldsymbol{F} = \boldsymbol{K} \cdot u
\end{equation}
其中外部作用 \(\boldsymbol{F}\)（力、压力、温度等）为已知，节点位移 \(u\) 为待求，系统刚度矩阵 \(\boldsymbol{K}\) 则包含材料参数（如弹性模量）。有限元方法常用于描述固体中的静态与动态问题，例如变形、应力分布或温度分布：把部件置于预期的受载状况之下，从而识别出局部的薄弱环节。


\subsection{最大坐标系下的刚体动力学}

在刚体动力学的具体建模中，存在两种典型的坐标选择方式。
\begin{itemize}
  \item 最大坐标方法：动力学系统中\textbf{每个刚体各自拥有六个自由度}，\textbf{这些自由度可以通过约束条件加以限制}，\textbf{每一个约束条件都会对应产生一个约束力}，这一思路是牛顿-欧拉方法的典型做法。以一台六轴工业机器人为例，在最大坐标方法下，其对应的方程组维度为三十。
  \item 最小坐标方法：\textbf{运动方程只针对系统实际的自由度建立}，\textbf{无需引入约束条件}，因而也\textbf{无需计算约束力}，这是拉格朗日方法的典型做法。同样以六轴工业机器人为例，在最小坐标方法下，其对应的方程组维度仅为六。
\end{itemize}

尽管最小坐标方法在方程规模上更为简洁，但从多个实际场景出发，仍然能够看出采用最大坐标方法的必要性：当约束条件（例如关节或碰撞接触）的数量随时间变化、当系统中存在并联运动结构、当系统具有自由运动的基座（例如卫星）、又或者需要求解动态支反力时，针对每一类具体情形单独设计求解方案往往并不经济，而最大坐标方法提供了一种统一的、可以涵盖各类情形的处理途径。


\subsection{跨领域仿真方法}

生产的网络化对仿真本身也提出了新的要求。在传统的生产环境中，机床、工件、工人、传感器与通信网络分属不同的专业领域，也各自被单独建模和仿真：机械专业计算力学行为，电气专业计算控制回路，物流专业计算节拍与产能，彼此之间几乎没有交集。而在互联的生产系统中，各要素之间的\textbf{相互作用}恰恰成为系统整体行为的决定因素，孤立的单领域仿真已不足以刻画真实表现，因此\textbf{必须进行整体性的仿真}：把此前彼此分离的机器、工人、传感器、通信等诸多过程\textbf{汇聚到同一个仿真环境之中}统一考察。这也正是以下几类跨领域仿真方法出现的动因。

具体而言，从系统仿真的视角出发，一个生产系统中以下几个方面都是相关的、需要被一并纳入模型：
\begin{itemize}
  \item \textbf{运动学与动力学}：设备自身的运动能力与受力行为；
  \item \textbf{传感器与执行器}：系统感知环境、并作用于环境的接口；
  \item \textbf{通信基础设施}：各组件之间交换信息的通道及其带宽与延迟；
  \item \textbf{数据处理}：对所采集数据进行的计算、评估与决策；
  \item \textbf{控制与管理系统（Leitsysteme）}：单元层以上的调度与指令下达；
  \item \textbf{用户界面}：人向系统下达指令、系统向人反馈状态的方式；
  \item \textbf{工人}：作业人员的行为、节拍与判断；
  \item \textbf{环境}：工件、周边设施以及外部条件；
  \item \textbf{相邻单元与更上层的控制技术}：处在本单元之外、却与之持续交互的部分。
\end{itemize}
这些方面此前分属不同专业、各自建模，而互联的生产恰恰要求把它们置于同一个模型中共同考察。

除了针对具体物理领域的专门仿真方法之外，还存在若干种通用性更强、可以跨越不同物理领域使用的建模与仿真范式。

\textbf{基于方程的仿真}是通过代数微分方程组来描述系统，其一般形式可以写成状态方程与输出方程两组关系式。这类仿真方式在机电一体化技术系统的仿真领域应用广泛，典型的建模载体是脚本语言，MATLAB即为其代表之一。

\textbf{信号导向的仿真}，是通过\textbf{作用图（Wirkungsplan）}来描述系统与过程。作用图是指借助方块、加法节点与分支节点、并通过作用线连接起来，对系统内部作用流程的一种符号化表示。以方框图形式呈现的模型，等价于给出了该模型背后的方程组，\textbf{模型的输入输出量（即信号流向）必须被明确规定}，这种方式在控制工程领域尤为常见，模型的各个部分还可以被封装为独立的模块，从而使信号流向更加清晰、整体结构更加直观，Simulink即是这类工具的代表。

\textbf{面向对象的仿真}是通过若干相互连接的元件来描述系统，物理上的关联通过势量与流量这两类物理量的表达式来刻画。与信号导向仿真不同的是，模型方程中的输入输出量并非预先规定，而是\textbf{随着各元件之间的连接关系自然浮现出来，连接本身传递的是物理量，不具有方向性，也无需事先对模型方程做数学层面的整理}，这一整理工作由仿真工具自动完成，Modelica即是这类描述语言的代表。

\textbf{事件离散的仿真}只对系统中依次发生的各类事件本身进行模拟，而不关心事件之间间隔的具体时间流逝过程：在离散过程的运行中出现的所有事件都会被重演，每一个事件都会触发一段依赖于该事件类型的事件处理程序；由此产生的输出，例如状态及状态转换的记录，还可以进一步用于统计诸如停留时长等其他特征量。

\subsection{面向工业4.0的概念与应用场景}

在具体的工业应用层面，\textbf{数字化工厂是对一整套由数字模型、方法与工具构成的综合网络的统称}，这些要素通过一体化的数据管理相互整合，其目标是对现实工厂中与产品相关的各类结构、流程与资源进行\textbf{整体性的规划、评估与持续改进}。

数字化工厂的核心目标在于加速并改进生产规划工作，并以并行工程的方式，使其与产品开发在时间上高度重叠，其应用范围覆盖从市场需求、设计、项目管理，到物流、规划、装配与调试、生产销售、服务、维护等生产全流程的各个环节。
