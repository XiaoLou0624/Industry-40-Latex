\section{增材制造中的数字化}

\subsection{增材制造}

增材制造，亦称3D打印，如图 \ref{fig:3dprinter} 所示，是指一系列基于CAD文件、通过逐层叠加的方式将材料连接起来、进而制造出三维构件的工艺方法。作为一项创新技术，它近年来呈现出几个清晰的发展趋势：低成本设备的可获得性不断提高，打印服务商的市场存在感持续增强，效率与构件质量的提升也使其逐步进入终端产品的生产环节。支撑这一发展趋势的，是增材制造相对于传统工艺所具备的五个方面的优势：灵活性、可持续性、个性化能力、无需专用工具、以及效率。

\begin{figure}[htbp]
  \centering
  \includegraphics[width=0.35\textwidth]{3dprinter.png}
  \caption{增材制造机器人}
  \label{fig:3dprinter}
\end{figure}

增材制造能够实现快速原型制作，可以制造复杂几何形状的构件，能够省去额外的加工步骤，摆脱了对专用工具的依赖，涵盖多种多样的工艺与材料，支持最大程度的个性化定制，并因无需针对形状定制专用工具而降低了相应的风险。但另一方面，这类工艺大多不适合大规模量产，且往往需要针对增材制造工艺本身重新设计构件结构，这也构成了其应用的局限。

将增材制造与其他制造方式加以对照，可以更清楚地看出其工艺特征：在减材制造（例如铣削）中，原料以整块材料的形式进入加工，经由工具去除多余部分后得到构件，加工过程中产生大量废料；在依赖工具的制造方式（例如注塑）中，原料以颗粒状进入加工，经由模具成型得到构件，废料相对较少；而在增材制造中，原料同样以颗粒状进入加工，但成型过程无需借助专用工具，构件通过材料的逐层叠加直接生成，产生的废料也最少。

在具体工艺层面，3D打印工艺大致可以分为三个大类。
\begin{itemize}
    \item 烧结与粉末打印工艺以选择性激光烧结（SLS）与电子束熔融（EBM）为代表：前者借助高功率激光将各层材料熔接起来，适用于塑料、金属、陶瓷等多种材料；后者在真空环境下利用电子束进行熔化，速度较SLS更快，主要用于钛等金属材料。
    \item 挤出工艺以熔融沉积成型（FDM）为代表，其原理是将材料在挤出装置中熔化，各层之间通过熔体本身实现粘合，是最为常见的"经典三维打印机"所采用的工艺，材料多为PLA或ABS等塑料。
    \item 液态塑料固化工艺则以光固化立体成型（SLA）与聚合物喷射（PJ）为代表：前者利用紫外光照射使液态、可硬化的树脂固化成型，具有较高的分辨率与精度，需要使用专用塑料；后者结合了FDM与SLA两种工艺的特点，先将液态塑料涂布于物体表面，再通过光源使其固化，同样依赖专用塑料材料。
\end{itemize}
完整的增材制造工艺链分为数字层面与物理层面两个部分。数字层面：首先通过构造得到CAD文件，再经过转换得到STL文件，进而经过路径规划得到CAM文件。这一过程中还会持续产生CAD/CAM数据、工艺数据、在线测量数据与机器数据，共同汇入一个统一的数据环境。物理层面：三维打印本身生成构件，随后经过后处理，并最终整合进入既有的生产流程之中。

\subsection{机器人在增材制造中的应用}

在具体的实现方式上，桌面级3D打印机代表了增材制造中最为经典的形态：沿三个笛卡尔坐标轴运动，不具备改变打印方向的能力。与之相对，基于机器人的增材制造则依托机器人这一通用的多轴运动装置：机器人可以自由编程，其机械结构须依据打印头的负载、精度要求与工作空间加以设计，由此获得了远高于桌面级设备的可扩展性与灵活性。

要在机器人增材制造中充分发挥这种灵活性，需要搭建一套围绕机器人打印头运作的单元：机器人将打印头作为末端执行器加以操控，同时可以借助快速换刀系统，使机器人在打印任务之外还能够承担其他用途。要实现这样的单元，还需要相应的路径控制能力：机器人的运动必须通过末端执行器的位置与姿态精确描述，必要时还可以借助移动机器人技术进一步扩大工作空间。

\subsection{CAD/CAM系统的作用}

一件新产品的诞生要经历构造、计算与制造这几个环节，而各类CAx方法正是这几个环节之间相互衔接的接口：CAD对应构造、CAP对应工艺规划、CAM对应制造、CAA对应装配、CAR对应机器人应用、CAQ对应质量保证、CAE对应工程计算、CAI对应检测，而CIM作为总括性的概念，则将市场分析、创意形成、方案预选、概念开发与验证等前期活动与产品开发、构造、工艺规划、制造、装配、质量控制这一贯穿始终的价值链联系在一起，其目标是在企业各个部门之间实现数据的贯通流动。在工业4.0的语境下，相应的软件解决方案则更加着眼于联网能力与集成能力，力图实现工艺数据的回流，同时也面临着数据管理、数据分发、数据透明度与数据可视化等方面的挑战，并要求在工艺发生变化时能够迅速做出相应调整。

具体到基于CAD/CAM系统的路径规划，其大致流程如下：
\begin{enumerate}
    \item 搭建机器人系统，为机器人定义相应的坐标系，并确定工具与工件及其各自关联的坐标系
    \item 加载工件（或事先已生成的G代码），并设定三维打印参数
    \item 切片处理，即将构件划分为若干层（可以是平面的，也可以是三维的），这一自动化的路径规划过程通常表现为大量微小的直线运动
    \item 机器人的起始位置需要给定一个明确的构型，否则机器人可能采用后续会导致碰撞的轴位配置
    \item 求解逆运动学问题，即完成坐标变换，将笛卡尔空间中的位置与姿态转化为机器人各轴的角度
    \item 生成（通常是特定厂商专属格式的）机器人代码
\end{enumerate}
以西门子NX软件为例，它集构造、仿真与制造于一体，提供贯通式的工艺链，能够针对多种工艺对机器人及机床加以仿真，具备集成化的数据管理能力，并通过NXopen提供支持C/C++、Visual Basic、Java、Python等语言的编程接口，用以实现工作步骤的自动化。以CAD/CAM系统为核心的增材制造工艺流程，大致可以归纳为五个环节：首先确定机器人与工具，定义相应的运动学结构及关联坐标系；随后确定打印参数，即针对所用材料明确期望的打印参数；接着进行切片处理，将构件划分为若干层；然后生成填充图案，即在外部轮廓内部生成填充图案；最后进行后处理，将打印路径转换为机器人的编程语言，并整合工具控制指令。

\subsection{仿真在增材制造中的作用}

作为工艺准备的工具，仿真在增材制造中大致可以分为工艺仿真、构件行为仿真与系统行为仿真三个方向。工艺仿真（例如订单仿真）用于预测增材加工过程中的温度行为：冷却行为对打印构件的尺寸稳定性至关重要：若前一层的温度过低，会导致层间粘合不良；若前一层的温度过高，则会因强度不足而导致失稳。这类仿真使得对翘曲变形的预测成为可能，而热传导本身又取决于材料、物体几何形状与环境条件等多重因素。

构件行为仿真则以熔融沉积成型（FDM）为例：由于各层之间存在分层现象，承载仿真本身较难开展；平行于打印层面方向的压缩载荷往往更早导致失效，而不平行或不垂直于打印层面方向的拉伸载荷则会因剪切行为而更早导致失效；据此可以通过按需设计的填充图案与填充密度，使构件的抗力水平与实际应用需求相匹配。

系统行为仿真则以硬件在环（HiL）为代表：这是一种对硬件进行测试的方式，其中输入、信号与传感器均可以被仿真出来，借助实时仿真可以测试诸如控制设计等内容——例如验证某一工艺的控制是否按预期方式运行、测试临界边界状态与各类故障可能性、以虚拟方式测试危险情形；这类仿真对系统的真实运行环境加以虚拟重现，其中复杂的动态建模在实际运行中可以进一步转化为数字孪生，从而实现设施的提前投入使用，具体可借助MATLAB／Simulink等工具完成。

\subsection{控制体系}

要理解控制技术在增材制造中所处的位置，可以借助一张覆盖工厂控制、规划、调度、单元、机床控制与工艺这几个层级的坐标系（图 \ref{fig:steuerungaddfert}）加以说明：自下而上依次为工艺层、单机控制层、机床控制层、单元层、调度层、规划层、工厂层，各层分别对应数控（NC）、机器人控制（RC）、运动控制（MC）、可编程逻辑控制器（SPS）、制造执行系统（MES）等不同的控制功能；越靠近工艺层，实时性要求就越强。经典的3D打印大致覆盖工艺层至机床控制层这几个层级，基于机器人的增材制造在此基础上进一步延伸至单元层，而工业4.0语境下基于机器人的增材制造则进一步延伸至调度层，体现出控制范围随系统复杂度提升而不断扩展的趋势。

\begin{figure}[htbp]
  \centering
  \includegraphics[width=0.8\textwidth]{steuerungaddfert.png}
  \caption{控制技术层级坐标系}
  \label{fig:steuerungaddfert}
\end{figure}

在具体的控制硬件层面，可编程逻辑控制器（SPS）作为核心控制单元发挥着多重作用：其中央处理单元负责信号之间的关联与循环处理，传感部分负责采集测量数据，执行部分负责驱动装置的开关与调节，人机界面则负责数据的可视化呈现与输入。以挤出工艺为例，温度调节是可编程逻辑控制器最重要的任务之一：通过人机界面或机器人程序设定目标温度，通过操控挤出装置的加热回路来调节温度，挤出装置内的温度传感器将测量值反馈至可编程逻辑控制器，并借助PID调节器实现温度的设定与保持；机器人控制器通常也被集成进可编程逻辑控制器之中，例如当无紧急停止按钮被按下、且温度处于允许范围之内时，才会释放挤出工艺的执行许可。

在更高层面上，基于数据的增材制造系统控制致力于依托生产数据提升系统灵活性：这要求实现数据的实时处理，而增材工艺本身无需换型时间、能够制造个性化产品，因而对高动态性与按需生产提出了要求，进而催生出兼具产量与品种灵活性的生产系统，乃至生产系统的自组织能力；其最终目标是通过对价值创造各环节参与主体的全面联网，确保相关信息能够实时可用，具体的控制回路涵盖规划、调度、工艺管理与机床控制这几个层面，并通过监控与诊断环节实现故障的识别与处理。围绕过程调节，还存在若干具体的挑战与相应的解决思路：一方面，需要将材料的施加速度与机器人的运动速度加以同步，解决思路是借助上层控制系统耦合机器人速度与打印速度，读取包含当前倍率在内的工具中心点速度，目标是使材料施加过程中保持恒定的截面；另一方面，构件中可能出现几何误差，相应的解决思路是进行误差补偿，在加工过程中对误差加以修正，并借助传感器加以支持。

\subsection{数据处理}

数字孪生通过数据与信息的连接将物理空间与数字空间联系在一起，通信在其中扮演着不可或缺的角色，物联网则是这一发展趋势的重要推动力；其目标在于实现对全生命周期的映射、对来自现实世界的数据加以分析与评估、依托数字孪生训练系统的行为与功能、并将当前状态加以虚拟化呈现，虚拟产品、虚拟生产与真实生产、真实产品之间通过性能数据相互关联，共同构成一个完整的协作平台，而工业安全则贯穿其中，是这一整套体系得以运转的基础前提。

围绕数据挖掘，跨行业数据挖掘标准流程（CRISP-DM）是一套标准化的流程模型，其目标在于实现跨行业的适用性、统一数据采集流程、为数据挖掘提供指导方针、并保持厂商中立。

在此基础上，机器学习作为一种借助人工智能预测打印构件产品质量的方法，其价值来源于工艺参数与对象参数之间高度复杂的相互依赖关系：人工智能模型借助已采集的数据加以训练，随后应用于未知数据。在增材制造领域，机器学习大致存在四类主要应用场景：工艺参数的优化与属性预测、缺陷检测与质量预测及工艺控制、几何偏差的控制、以及成本估算。

\paragraph{示例：渐进式制造与实验室实践}

渐进式制造（Incremental Manufacturing）这一构想，源于对不同批量规模下制造成本变化趋势的观察。随着车型种类的增加，每种构件所需应对的变体数量也随之增加。在这一背景下，与依赖工具的制造方式相比，增材制造及渐进式制造在自动化程度与生产率方面具有明显优势，中小批量的生产借助其灵活且可扩展的制造技术往往更具成本效益，也就意味着更低的产品专属投资。

渐进式制造的核心构想是以多个小的增量步骤而非一次性成型的方式来制造构件。其起点是一件预先制造好的半成品，在此基础上通过增材与减材两种方式加以最终成型。

支撑这一构想落地的是渐进式制造实验室（Incremental Manufacturing Lab）：其中基于颗粒挤出的机器人三维打印（FDM工艺）具备约每小时一点五千克的堆积速率；基于电弧丝材的机器人三维打印（WAAM工艺）具备约每小时四千克的堆积速率，热输入较低，且打印过程无需支撑结构；此外还配备机器人化的切削加工能力，具备工序内切屑捕集及对混合材料进行加工的能力；线性轴与旋转倾斜工作台的配置，则为整个实验室提供了额外的灵活性。
