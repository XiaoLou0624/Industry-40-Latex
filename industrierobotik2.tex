\section{工业机器人II}

\subsection{人机协作}

\ref{subsec:intelligent} 小节中，我们通过飞机铆接案例提到，工业机器人和人各有各的长处，也各有各的短板。机器人力气大、重复精度高、干活快，缺点是流程比较死板、只能按事先编好的程序走、而且出于安全考虑对周围环境要求很严格。人正好相反：擅长感知环境、随机应变、手指灵巧、行动自由，但容易疲劳，干出来的活质量也会有波动。人机协作的思路很简单，就是把两者的优点凑到一起：机器人负责重复、费力、需要精度的部分，人负责需要判断、灵活应对的部分，取长补短。

传统自动化生产线的做法是把人和机器人彻底隔开：各自有独立的工作区域，互不干扰，流程也是固定死的，追求的是大批量、高重复精度。人机协作则完全不同，它让人和机器人共用同一个工作空间协同作业，这就要求系统必须能可靠地识别和追踪人的位置，对整个工作空间进行实时监控，一旦有风险就能及时反应；作为回报，这种方式能支持更灵活、更容易调整的个性化生产流程，不用像传统产线那样"一改流程就要大改设备"。

人和机器人在同一空间里干活，紧密程度可以从"完全不挨着"到"手拉手一起干"分成五个等级，如图  所示。

\begin{enumerate}
    \item 单元（Zelle），也就是最传统的机器人工作站：机器人被围栏关在自己的区域里，和人的工作区完全没有交集，是最基础也是最安全的形式。
    \item 共存（Koexistenz）：人和机器人之间不再有物理围栏隔开，但各自的工作范围依然不重叠，谁也不会闯进对方的地盘。
    \item 同步（Synchronisiert）：两者的工作范围开始出现重叠，但系统会保证他们不会同时出现在这个重叠区域里，是错开时间共用同一块空间。
    \item 合作（Kooperation）：人和机器人可以同时出现在共同的工作空间里，但彼此并不共同操作同一个工件，各干各的活，只是空间上离得更近了。
    \item 协作（Kollaboration）：人和机器人真正共同对同一个工件进行操作，比如机器人扶着零件、人在旁边动手加工，配合程度最高，对安全技术的要求也最高。
\end{enumerate}

要实现比较高等级的人机协作，最大的挑战是系统要能把传感、感知和反应整合到一起，实时应对生产过程中各种不确定的变化，而且流程一旦要调整，最好不需要重新给机器人编程就能适应。要做到这一点，背后需要执行机构、传感器和智能软件三者高度配合协调，还需要引入性能足够强的传感器以及配套的数据处理算法，才能让机器人看得懂周围发生了什么、反应得过来。

从法规层面看，人机协作系统的安全依据主要是ISO 10218标准以及ISO/TS 15066技术规范，为怎么安全地设计这类系统提供了框架。从技术落地看，科研项目和产业界已经出现了一些初步的集成案例，市场上也已经有专门为人机协作设计的机器人产品，比如Kuka LBR iiwa、ABB YuMi、Universal Robots UR3、Fanuc CR-35iA、Rethink Robotics Sawyer、Franka Emika等，如图 \ref{fig:kollaborationstand} 所示。不过即便经济效益和人体工学方面的好处都很明显，这类系统目前整体还没有大规模普及。在规划设计工具方面，已经有专门的人体仿真系统（比如ema）和各家机器人厂商自己的仿真软件，但业内还缺少一套能把"人"和"机器人"放在一起统一规划人机协作场景的集成工具，这也是目前有待解决的问题。

\subsection{安全规范与概念}

既然人和机器人要共用一个空间，安全上到底该怎么保证？这一节主要围绕两份标准展开——DIN EN ISO 10218（机器人本体和系统的通用安全标准）和ISO/TS 15066（专门针对人机协作的技术规范）。

保证安全大致有两条路：一条是本质安全设计，从机械结构本身入手，比如让机器人边缘更圆滑、材质更软，从根源上降低伤害风险；另一条是功能安全，靠传感器、控制器这些主动防护功能来实时监测和响应危险，比如检测到人靠近就减速或停止。

机械安全标准分三个层级，像金字塔一样，如图 \ref{fig:sicherheitsnormen} 所示。
\begin{itemize}
    \item 最底层是A类标准，讲的是最基础、适用于所有机械的安全设计原则（比如EN ISO 12100）；
    \item 中间是B类标准，是某一类通用安全技术要求（比如安全距离怎么算、急停装置怎么设计）；
    \item 最上层是C类标准，针对具体某一类机械给出非常具体的安全要求，工业机器人相关的EN ISO 10218-1、10218-2、ISO/TS 15066都属于这一层。层级越往上越具体、越贴近实际应用。
\end{itemize}

\paragraph{DIN EN ISO 10218：机器人的基本安全标准}

这份标准分两部分。第一部分针对机器人本体，规定了工业机器人和机器人系统特有的危险源，以及对机器人本身（作为系统的一个组成部分）的安全要求。第二部分针对机器人系统与集成，规定了机器人被集成到产线或工作单元时会带来的额外风险，以及在集成安装过程中如何保证安全。简单说，第一部分管"机器人本身造得安不安全"，第二部分管"把机器人装进产线时怎么装才安全"。

\paragraph{ISO/TS 15066：专门为人机协作补充的规范}

ISO/TS 15066是2016年发布的技术规范，是对EN ISO 10218第二部分的扩展，专门针对协作机器人系统的设计。它一方面讲怎么设计协作应用、怎么做危险识别和风险分析，另一方面给出了协作应用需要满足的具体要求，包括安全功能设计、协作工位怎么布置、协作机器人怎么使用和运行。可以说，10218是通用机器人安全的地基，TS 15066是专门为"人机共处"这件事加盖的一层楼。

ISO/TS 15066规定了四种能保证人机安全共处的方法，实际应用中常常组合使用。

方法一是安全定向停止：人进入协作空间前，机器人必须先进入安全停止状态；如果安全装置被触发后没法从后方绕过，机器人还能自动重新启动。这种方式要求较高的安全性能等级（Performance Level d、类别3），停止方式可以是0到2类停机中的任意一种。本质上，人只能在机器人完全静止时才能靠近它，所以不可能发生碰撞。

方法二是手动引导：同样要求人进入协作空间前机器人先停止，然后通过一个靠近工具中心点（TCP）的三级确认装置来激活手动引导模式，这时机器人只能被人用安全的、大幅降低的速度手动操纵。也就是说，人始终只能接触静止或被自己缓慢操控的机器人，同样不会发生意外碰撞。

方法三是速度和间距监控：这是唯一允许机器人和人同时在协作空间内运动的方式。系统会实时监测人和机器人之间的距离，机器人的速度会随着这个距离动态调整——离得越近走得越慢，一旦距离小于安全阈值，机器人会提前停下，从而避免碰撞。这里安全距离的计算有一套标准公式（EN ISO 13855）：
\begin{equation}
    S = (K × T) + C
\end{equation}

其中 S 是最小安全距离（mm），K 是人接近的速度参数（mm/s），T 是整个系统的反应加制动时间（s），C 是额外的侵入余量（mm）。这个公式假设机器人是静止的、只有人在移动。

TS 15066在此基础上给出了更精细的动态计算公式，把机器人自身的运动也考虑了进去：
\begin{equation}
    s_p(t₀) = s_h + s_r + s_s + c + z_d + z_r
\end{equation}

其中 \(s_h\) 是人的位移量（mm）、\(s_r\) 是机器人的位移量（mm）、\(s_s\) 是机器人的制动距离（mm）、c 是侵入余量（mm）、\(z_d\) 和 \(z_r\) 分别是人和机器人位置的测量不确定度（mm）。相比前一个公式，这个版本同时考虑了人和机器人双方都在运动、以及定位误差带来的不确定性，算出来的安全距离更贴近人机协作的真实场景。实际应用的例子就是ABB YuMi这类协作机器人。

方法四是功率和力限制：这是唯一允许人和机器人发生物理接触（无论是有意还是无意）的方式，靠的是机器人本身在结构设计上就足够"温和"（本质安全设计），再叠加安全功能（比如限速、限力）来降低风险。这里需要先区分碰撞的类型：一种是准静态接触（俗称"夹挤"），人的身体部位被卡在机器人和某个固定障碍物之间，没法及时抽身；另一种是瞬态接触（俗称"碰撞"），人没有被夹住，可以及时躲开。针对这两种情况，降低风险的手段又分被动和主动两类：被动措施包括增大接触面积（减小局部压强）、用柔软材料或缓冲结构吸收冲击能量；主动措施则包括限制机器人的输出力和功率、限制运动速度、限制机器人能活动的空间范围。所有这些限值最终都要落到量化标准上：TS 15066的附录A给出了人体各部位（前臂、手指、手掌、手背、大腿、膝盖等）能承受的准静态接触压强和瞬态接触峰值力的具体数值，以及对应的弹性系数，一旦实际可能发生的碰撞力超过这些限值，就必须采取额外的防护措施。
