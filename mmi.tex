\section{人机交互}

\subsection{互动与沟通}
\label{subsec:kommunikation}

互动与沟通这两个词经常混用，但严格来说不完全一样。

\textbf{沟通（Kommunikation）} 指的是信息的传递或交换，可以是一个动作加一个反应，也可能只是单向的信息发出。。

\textbf{互动（Interaktion）}强调的是人与人之间的相互作用。互动一定是双向的：你做了动作，对方也做出反应。

两者有很大的重叠，但互动更强调来回，沟通更强调信息本身。

\paragraph{Watzlawick 的五条沟通公理}

\begin{enumerate}
    \item 人不可能不沟通，沉默、表情、姿态也是在沟通。
    \item 每条信息都有两层含义：内容层面和关系层面。
    \item 人类沟通同时用两种语言：数字化语言逻辑清晰、有语法规则；模拟化语言靠语气、表情、肢体动作。
    \item 沟通是循环的因果关系：你说的话是对方反应的原因，对方的反应又成了你下一句话的原因。
    \item 沟通要么是对称的，要么是互补的。对称是双方地位平等，互补是双方地位不对等。
\end{enumerate}

\paragraph{Schulz von Thun 的沟通四层模型}

你说的每一句话，其实同时包含四层信息：
\begin{enumerate}
    \item 事实
    \item 自我表露：透露了什么状态或想法
    \item 关系暗示：怎么看待对方、你们是什么关系
    \item 诉求：说这句话是想让对方做什么
\end{enumerate}
例如副驾驶对司机说前面是绿灯。表面上只是在陈述一个事实，但背后可能同时是我有点着急（自我表露）、我觉得你反应有点慢（关系暗示，可能让人不爽）、你可以走了（诉求）。同一句话，说话人的意图和听话人的理解经常对不上，这就是很多沟通误会的根源。

\paragraph{Jones \& Gerard 的四种社会互动模式}

这个理论描述互动时的模式：
\begin{enumerate}
    \item 完全互动：双方的目标和行为高度一致，配合得很好。
    \item 非对称互动：一方完全按自己的节奏来，不太理会对方。
    \item 伪互动：表面在互动，实际上双方都只顾着实现自己的目标，没有真正配合。
    \item 反应式互动：只是被动地对对方的刺激做出反应，没有自己的主动计划。
\end{enumerate}
这一节是为后面几节做铺垫。理解人与人之间沟通的复杂性，是理解人机交互设计难点的第一步。

\subsection{人与机器的沟通}
\label{subsec:contactmanmachine}

沟通要发生，需要两个基本前提：
\begin{itemize}
    \item 共同的符号库（gemeinsamer Zeichenvorrat）：双方得用同一套语言或符号系统。
    \item 通道和兼容的收发器官：得有一条传播路径，发送和接收设备也得匹配。
\end{itemize}

\paragraph{Shannon \& Weaver 的发送者-接收者模型}

Shannon \& Weaver 的发送者-接收者模型把一次沟通拆成信息源 → 发送者（编码） → 信号 → 传输通道 → 接收者（解码） → 目标这几个步骤。发送者把要传达的信息编码成信号，信号通过通信信道传输，接收者把收到的信号解码还原成信息。\textbf{干扰（Störungen） 的来源有}：
\begin{itemize}
    \item 信道里的噪声
    \item 解码中的错误
    \item 符号库不兼容
\end{itemize}

\vspace{2em}

沿用 Shannon \& Weaver 的框架，\textbf{沟通可以从三个层面来分析}，每个层面回答一个不同的问题：
\begin{itemize}
    \item \textbf{技术层面（technical）}：关注符号有没有被正确传输。
    \item \textbf{语义层面（semantic）}：关注传输的符号有没有精确传达出想表达的含义。
    \item \textbf{效果层面（effectiveness）}：关注收到的信息有没有有效地引导出预期的行为。
\end{itemize}


\subsection{技术可能性与限制}
\label{subsec:restriktoren}

人的感官既是接收器，也是发送器。人身上天生自带一整套传感器（Sensorik）和执行器（Aktorik）。人本身就是一套多模态的收发系统。

机器和人之间主要有三种传输方式：
\begin{itemize}
    \item 光学传输：机器靠指示灯、显示器发送，人靠眼睛接收。人靠表情、手势发送；机器靠摄像头接收。
    \item 声学传输：机器靠运行噪音、语音播放发送，人靠耳朵接收。人靠嘴巴说话发送，机器靠麦克风接收。
    \item 触觉传输：机器靠移动发送，人靠皮肤接收。人靠身体发送，机器靠按键、键盘、触摸屏接收。
\end{itemize}
人这一侧的干扰往往来自生理或环境限制，机器这一侧的干扰更多来自设备本身的性能或故障。

干扰可以按沟通三层面来分类。回顾 \ref{subsec:contactmanmachine} 节提到的技术层面、语义层面、效果层面，这里我们把\textbf{常见干扰}具体归到了三个层级：
\begin{itemize}
    \item 技术层面的干扰：背景噪声、信号衰减
    \item 语义层面的干扰：语言和手势不同、编码方式不同、符号对应关系不同、字符集不同
    \item 效果层面的干扰：理解和意图相反、信息含糊不清、缺乏上下文
\end{itemize}
出了沟通问题之后可以根据这个分类来定位问题出在哪一层。

由于人和机器目前还没法做到完全对等地互相理解，因此我们需要双向的适应策略。
\begin{itemize}
    \item 人向机器靠拢：因为人机之间共同的"符号库"有限，交互方式也是由机器开发者预先设定好的，通常也不支持非语言沟通（手势、表情）,所以人往往需要调整自己的说话和行为方式，比如使用简化的、基于关键词的语言。例如直接说"Alexa，割草坪"智能音箱听不懂，得按规定格式说“Alexa，请割草坪”才能被识别执行。
    \item 机器向人靠拢：借助自学习算法扩展机器能识别的符号库、用人工智能方法识别非语言信息，具体体现在把多个沟通渠道的信息语义化地组合起来分析、让机器学习原本没有预设的新反应、以及对自然语言进行理解和解释。这是让机器越来越"像人"、越来越好用的方向。
\end{itemize}

\paragraph{人机交互的四种模式}

我们用一个“真实-虚拟”的矩阵把人机交互分成四种模式，如表 \ref{tab:realvirtualmatrix} 所示。

\begin{table}[htbp]
    \centering
    \caption{真实-虚拟矩阵}
    \label{tab:realvirtualmatrix}
    \begin{tabular}{lcc}
        \toprule
        - & 真实 & 虚拟 \\
        \midrule
        人 & 对话系统 & Human-in-the-Loop \\
        机器 & Hardware-in-the-Loop & 仿真 \\
        \bottomrule
    \end{tabular}
\end{table}

人和真实机器之间的交流是对话系统；人进入一个虚拟环境里参与和影响系统运行,就是 Human in the Loop。真实的硬件参与到一个虚拟系统的运行验证中,是 Hardware in the Loop。而双方都在虚拟世界里,就是纯粹的仿真。
