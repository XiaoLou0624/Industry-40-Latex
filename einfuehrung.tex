\section{课程简介}

\subsection{工业4.0的概念}

工业发展的历史通常被划分为\textbf{四次工业革命}：
\begin{itemize}
    \item 工业 1.0 指的是以蒸汽机为基础的机械化生产
    \item 工业 2.0 指的是以流水线为基础的大规模生产
    \item 工业 3.0 指的是通过信息技术和计算机实现的自动化生产
    \item 工业 4.0 指的是通过网络化实现的智能化生产
\end{itemize}

\textbf{信息物理系统（Cyber-Physical Systems, CPS）}指的是物理设备和数字系统高度耦合的系统。它可以让设备直接在互联网中互相通讯，是未来生产的核心。例如一台机床可以通过传感器采集运行数据，通过控制器和网络接口传输数据，并利用软件系统对状态进行监测、分析和优化。

\textbf{物联网（IoT）}的本质就是让物理世界中的物体具备感知、通信、计算和行动能力。下面这七点对应实现物联网所需的前提：
\begin{enumerate}
    \item 泛在通信（Uniquitäre Kommunikation）：物联网设备数量级远超传统互联网终端，且分布分散。因此要求通信不再局限于Wi-Fi/以太网，而要覆盖低功耗广域网、蜂窝网络、短距无线等多种技术组合，做到随时随地都能连上。
    \item 大数据与云计算（Big Data and Cloud Computing）：大量物联网设备持续产生数据，使得单个终端不足以处理，因此需要云计算提和大数据技术来支持。
    \item 整体环境感知（Holistische Umwelterfassung）：单一传感器只能提供局部环境信息，因此需要整体环境感知来构造完整且可用于决策的环境模型。
    \item 所有实体的移动性（Mobilität aller Entitäten）：IoT中的物往往不是静止的。这要求网络架构支持无缝切换、位置感知以及移动场景下的服务连续性。
    \item 能量自主（Hierachiefreie Energieautonomie）：很多IoT节点部署在无法接入电网、也难以频繁更换电池的地方。因此需要不依赖固定电源的供能方式，实现真正的部署后免维护。
\end{enumerate}
这五点合在一起才能构成物联网所需的完整技术链条。
