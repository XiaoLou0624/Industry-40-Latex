\section{传感器系统}

\subsection{机器人传感器}

\subsubsection{传感器的定义、任务与分类}

工业机器人本身按照预先编好的程序动作，理论上并不需要感知外界。但现实生产中，很多情况让机器人必须依靠传感器才能正常工作。典型情形有：
\begin{itemize}
    \item \textbf{工件有时无法有序摆放}
    \item \textbf{工件和工件夹具的公差过大}
    \item \textbf{工件被连续移动的传送装置搬运}
    \item \textbf{转向角未知}，比如装配一个旋转部件时，机器人得先识别出它当前处于什么角度。
    \item \textbf{工件本身柔软易变形}
    \item \textbf{硬自动化容易出故障}，用传感器可以及时发现并灵活应对，从而减少人工质检和人工干预的次数
    \item \textbf{加工精度要求超过了机器人精度}，机器人自身的定位精度不一定够用，要靠传感器来补足。
    \item \textbf{机器人编程本身很繁琐}，可以借助传感器自动生成运动轨迹，或者先粗略编好轨迹，再叠加传感器做精细修正。
\end{itemize}

传感器是一种测量值拾取器，它获取物体的属性、状态和过程信息，并把最重要的输入信号转换成合适的输出信号。按照传感器安装的位置和作用对象，可以分为\textbf{内部传感器}和\textbf{外部传感器}两类。内部传感器让\textbf{机器人感知自己的内部状态}，比如速度、位置、力和力矩；外部传感器则\textbf{负责获取机器人所处环境的信息}，包括感知被操作对象和周围环境的状态、识别和判断工件的性质、测量各种物理量，以及分析周围场景。

外部传感器按照工作原理又可以分为接触式和非接触式两大类。接触式传感器包括触觉类和力/力矩类；非接触式传感器则包括视频光学类、感应/电容/磁性类、光学测距类，以及超声波类。整个传感器分类结构如图 \ref{fig:sensorstruktur} 所示。

\subsubsection{非接触式传感器}

视频光学传感器的工作方式是先拍摄工件场景的图像，再通过计算机做图像处理，从而判断物体的种类、数量和位置。二值图像处理系统对光照条件的变化非常敏感，很多情况下需要配合专门的光照控制装置；灰度图像处理系统的可靠性则明显更好。常见的照明方式包括透射光和反射光两种：透射光用来呈现透明物体的内部结构，或者拍出不透明物体的轮廓；反射光则用来突出物体的表面结构，常用于工件识别。

视频光学传感器另一个重要应用方向是物体识别，如图 \ref{fig:nichtberuhrendesensor} 所示。对一套自动识别系统的要求包括：在给定条件下保证足够高的读取可靠性、满足输送环节所需的读取速度、能够生成足够多样的识别标记、读取距离能够根据实际情况调整、与供应链上其他环节保持兼容，同时还要控制识别系统和相关设备的成本。识别所依据的特征既可以是物体本身固有的属性，也可以是人工添加的识别标记，比如二维码、RFID等。

\subsection{面向工业4.0数字化的3D测量技术}

数字化的本质是\textbf{把物体表面用离散化的方式重建出来}，\textbf{测量和检测数据要能够反映产品和加工过程的状态}。

激光类3D测量系统（全站仪、激光跟踪仪、激光扫描仪）在原理上都是\textbf{极坐标测量}：分别测出到目标点的距离和两个方向角，再合成为三维坐标。

距离测量最基本的三种方法是
\begin{itemize}
    \item \textbf{脉冲飞行时间法}通过测量激光脉冲往返的飞行时间来计算距离。
    \item \textbf{相位比较法}通过观测和分析持续发射的载波信号的相位移完成测距，通常精度更高但量程受限；
    \item \textbf{三角测量法}在固定基线的前提下，通过观测角度的变化来推算距离。
\end{itemize}
角度测量方面，水平角和垂直角由\textbf{角度编码器（Winkelencoder）}测得。需要注意这两类系统在原理上的分工：激光系统依靠测距 + 测角直接得到点的极坐标，而相机系统则依靠三角测量法获取深度信息，通过已知基线上的多个视角对同一物点的交会来反算其空间坐标。
