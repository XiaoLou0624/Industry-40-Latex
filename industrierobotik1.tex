\section{工业机器人I}

\subsection{机器人结构与运动学}

在工厂里，我们经常需要设备把零件"抓起来、移动、放下"，这类设备统称为操作设备（Handhabungsgeräte）。它们大致分三种。第一种靠人手动操作或远程遥控，比如工人直接搬运物体。第二种是固定程序运动装置，动作路线是靠机械结构事先"焊死"的，改变动作就得换零件，成本低但不灵活。第三种是自由可编程运动装置，它靠程序控制运动，改变任务只需要改程序，工业机器人就属于这一类。

除了按靠人操作 / 固定程序 / 自由可编程这个维度对操作设备做分类之外，针对工业机器人本
身，还可以按其程序自主性的高低做进一步细分，这个维度关注的问题是机器人在运行过程
中，能在多大程度上自己做主，而不是完全按照人预先写死的程序走。
\begin{itemize}
    \item 无自主程序影响（ohne selbsttätige Programmbeeinflussung）：机器人严格按照事先编好的程序执行，运行过程中不会根据外部信息自己调整或切换程序，是自主性最低的一类，也是传统工业机器人最常见的工作方式。
    \item 有自主程序选择（mit selbsttätiger Programmselektion）：机器人事先存有若干套可选程序，运行时能够根据传感器信号或外部条件，自己判断该调用哪一套程序，但每套程序本身的内容依然是预先写死的，机器人只是在选哪个上具备一定自主权，而不能修改程序内容本身。
    \item 有自主程序适应（mit selbsttätiger Programmadaption）：机器人不仅能选程序，还能根据实时感知到的环境或工件状态，对程序本身的参数甚至逻辑做出动态调整，这是自主性最高的一类，机器人开始具备一定的自适应加工能力。
\end{itemize}
这三个层级本质上描述的是机器人从完全被动执行逐步走向能感知、能判断、能调整的过程。

工业机器人可以看作由多个刚性连杆和关节组成的运动链。连杆（Glied）是机器人中近似刚性的构件。关节（Gelenk）连接两个连杆并允许它们产生相对运动的。轴（Achse）是指机器人中被驱动和控制的运动轴。关节的运动主要分为转动和平移。多个关节和连杆依次连接，构成了机器人的运动链。

自由度（Freiheitsgrad）表示一个机械系统能够独立运动的参数数量。注意：关节数量不一定等于自由度数量。因为不同关节产生的运动可能存在约束，并非每一个关节都提供一个独立自由度。

机器人系统中会同时存在多个坐标系，例如机器人基坐标系、参考坐标系、以及末端执行器坐标系。同一个点在不同坐标系中的坐标不同，因此需要通过坐标变换建立他们之间的关系。两个坐标系之间的刚体变换由旋转和平移组成。

假设有两个坐标系 \(A\) 和 \(B\)。如果 \(B\) 相对于 \(A\) 只是移动了，没有旋转，那么一个点从 \(B\) 坐标系转换到 \(A\) 坐标系时，只需要加上两个坐标系原点之间的位移：
\begin{equation}
    {}^A\mathbf p={}^B\mathbf p+{}^A\mathbf t_B
\end{equation}

但现实中 \(B\) 往往还相对于 \(A\) 发生了旋转。因此首先需要用旋转矩阵 \({}^A R_B\) 把向量的方向从 \(B\) 的坐标轴转换成 \(A\) 的坐标轴：

\begin{equation}
    \label{eq:rotationtranslation}
    {}^A\mathbf p={}^A R_B\,{}^B\mathbf p+{}^A\mathbf t_B
\end{equation}

这里 ${}^A R_B$ 表示“坐标系 \(B\) 相对于坐标系 \(A\) 的方向关系”，而 ${}^A\mathbf t_B$ 表示“\(B\) 的原点在 \(A\) 中的位置”。可以记成：下标是从哪里来，上标是到哪里去。

但是表达式 \ref{eq:rotationtranslation} 还是有一点麻烦，因为旋转是乘矩阵，平移却是加向量。为了让旋转和平移能够统一用一次矩阵乘法完成，我们引入第四个齐次坐标，把三维点 \((x,y,z)^T\) 写成 \((x,y,z,1)^T\)。然后定义齐次变换矩阵为
\begin{equation}
    {}^A T_B=
    \begin{bmatrix}
        {}^A R_B & {}^A\mathbf t_B\\
        0&0&0&1
    \end{bmatrix}
\end{equation}

这样表达式 \ref{eq:rotationtranslation} 就可以写成
\begin{equation}
    \begin{bmatrix}
        {}^A\mathbf p\\
        1
    \end{bmatrix}
    ={}^A T_B
    \begin{bmatrix}
        {}^B\mathbf p\\
        1
    \end{bmatrix}
\end{equation}

这就是齐次变换的意义：用一个矩阵同时表示两个坐标系之间的旋转和平移。

\paragraph{示例}

图 \ref{fig:roboterundwelt} 展示了一个机器人在操控一个物体。这个场景有4个坐标系，分别是世界坐标系W、机器人的基座坐标系B、机器人末端坐标系TCP、以及物体坐标系O。图中已知三个变换 \({}^W T_B\)、\({}^B T_{TCP}\)、和\({}^W T_O\)；两个未知变换 \({}^W T_{TCP}\) 和 \({}^{TCP}T_O\)。首先我们要明确：\({}^W T_B\) 表示 \(B\to W\)。接下来我们要来求这两个未知变换。

\begin{figure}[htbp]
  \centering
  \includegraphics[width=0.5\textwidth]{roboterundwelt.png}
  \caption{一个机器人在环境中操控一个物体，它们有各自的坐标。}
  \label{fig:roboterundwelt}
\end{figure}

我们使用坐标变换的串联将 \(TCP\to B\) 和 \(B\to W\) 连接起来，自然就得到了 \(TCP\to B\to W\)。对应的矩阵就是 \({}^W T_B\,{}^B T_{TCP}\)。因此
\begin{equation}
{}^W T_{TCP}={}^W T_B\,{}^B T_{TCP}
\end{equation}
接下来我们求 \({}^{TCP}T_O\)。我们已知\({}^W T_O\)，也就是\(O\rightarrow W\)。但目标不是世界坐标系，而是 TCP，因此还需要：\(W\rightarrow TCP\)。问题在于我们前面得到的是 \(TCP\rightarrow W\)。方向反了，必须取逆：\({}^{TCP}T_W=({}^W T_{TCP})^{-1}\)。因此完整路径 \(O\rightarrow W\rightarrow TCP\) 的表达式为
\begin{equation}
    {}^{TCP}T_O=({}^W T_{TCP})^{-1}\,{}^W T_O=\left({}^W T_B\,{}^B T_{TCP}\right)^{-1}{}^W T_O
\end{equation}


\subsection{特性参数}

在知道机器人怎么构成、怎么运动之后，我们接下来要用特性参数（Kenngrößen）来描述这台机器人到底能不能完成某项任务。性能参数分为4大类，分别为几何参数、负载参数、精度参数、和运动参数。
\begin{itemize}
    \item \emph{几何参数}主要描述机器人的尺寸以及它能够覆盖的空间。这个空间准确来说就是机器人末端执行器能够到达的所有位置所组成的空间。比如一台安装在地面上的机械臂末端能够到达的位置会受到连杆长度、关节类型、关节转角范围限制。所以在设计生产线时，第一个问题往往不是精度，而是够不够得到。
    \item \emph{负载参数}描述的是机器人的负载。这个参数不只是机器人抓起来的工件重量，因为机器人末端通常还装有夹具或者工具。机器人承受的静态载荷由工具和操作对象产生的重力以及过程力共同组成。过程力可以理解为机器人执行任务时外部过程施加的力。因此判断一台机器人是否适合某项任务，不能只看工件的重量，还需要考虑工具以及实际加工过程中产生的力。
    \item \emph{精度参数}描述的是机器人操作的精度。这里有两个概念：定位精度和重复精度，它们是不同的。假设我们要求机器人每次都移动到100mm的位置，进行了5次运动，结果都是 100.50，100.51，100.49，100.50，100.51mm。这些结果彼此非常接近100.50，所以重复精度很好，但目标明明是100.00，所以定位精度并不好。前面讨论的是机器人最终停在哪里。但有些机器人任务不能只关心终点，例如焊接时，机器人需要沿着焊缝运动。所以在姿态精度之外，还要讲究轨迹精度，轨迹精度同样有定位精度和重复精度的细分。
    \item \emph{运动参数}的概念可以从生产效率理解：假设机器人完成一个 Pick \& Place，有抓取、移动、放置、返回四个步骤。如果整个过程需要5秒，这个5秒就是循环时间，这是一个很典型的运动参数。速度、加速度、稳定时间等也是运动参数。
\end{itemize}
这四个参数共同描述了机器人的性能。简而言之，几何参数反映机器人能覆盖多大的操作范围，负载函数反映机器人能承受多少负载，精度参数反映机器人的准确度和重复性，运动参数描述机器人的运动速度。

\subsection{末端执行器与安全技术}

机器人本身只是一副"骨架"，真正决定它能干什么活的，是装在机械臂末端的末端执行器（Endeffektor）。

\paragraph{夹爪是怎么抓住零件的}

夹爪要把一个零件稳稳固定住，靠的无非是三种抓力原理。
\begin{itemize}
    \item 力锁合（Kraftschluss）：靠某种持续作用的力把物体夹紧，比如靠摩擦力（普通的机械手指夹紧零件）、靠负压（真空吸盘吸住平面零件）、或者靠磁力（电磁铁吸住铁质零件）。
    \item 形锁合（Formschluss）：靠零件和夹具的形状互相咬合、卡住来固定，比如两个曲面拼合到一起、或者靠形状匹配把零件"卡"在夹具里。
    \item 质锁合（Stoffschluss）：靠物质本身的状态变化把物体粘住，比如把液体冻结成冰来临时固定零件。
\end{itemize}

这三种夹爪形态的示例如图 \ref{fig:halterprinzipien} 所示。它们各有适用场景：力锁合最常见也最灵活，形锁合精度高但夹具要专门定制，质锁合则多用于特殊工艺（比如玻璃、易碎品的临时固定）。

光有夹爪还不够，实际生产中还需要几个"帮手"。
\begin{itemize}
    \item 自动换爪系统：当机器人需要频繁切换不同的夹爪或工具时，可以在机器人手腕和工具之间加一块"适配板"，任务变了就自动换一套工具，不用人工去拧螺丝换夹爪。
    \item 碰撞保护装置：适配板之间靠气压支撑，正常工作时是刚性连接，一旦工具意外碰撞受到过载，气压结构会自动松开缓冲，避免损坏机器人或工件。
    \item 位置补偿装置：在装配这类需要高精度对准的工序中，补偿装置能允许末端执行器在小范围内自由浮动、自动纠正位置和角度偏差，同时又能防止绕装配轴转动跑偏，特别适合精密插装、螺丝拧入这类任务。
\end{itemize}

\paragraph{机器人周围的安全防护}

机器人力量大、动作快，一旦和人发生碰撞很危险，所以工厂里必须有防护装置把人和机器人的工作区域隔开或及时停机。这些防护装置按方式可以分为两大类。
\begin{itemize}
    \item 隔离型防护：物理上把人挡在机器人工作区之外。它又分固定式（比如围栏、护栏，装好了不会动，想进去必须拆）和活动式（比如安全门，人要进去就得先打开门，门一开机器人就自动停）。
    \item 非隔离型防护：不靠物理挡板，而是靠感知或操作方式来保证安全。其中接触式的例子是安全垫。人一踩上去，压力传感器就触发停机；非接触式的例子是光幕、激光扫描仪，人一旦进入危险区域就被光电传感器探测到并立即停机。
    \item 靠操作动作来保证安全：比如双手按钮开关（必须同时用两只手按下才能启动，防止手伸进危险区），以及使能开关（操作人员必须持续按住某个开关，机器人才允许运行，一松手就停，专门用于需要人靠近机器人手动操作或调试的场景）。
\end{itemize}

\subsection{轨迹规划与生成}

机器人要完成一个动作，光有夹爪和骨架还不够，还得知道"该怎么走"。

轨迹规划（Bahnplanung）要做的就是从几何角度把一个运动任务描述清楚，需要同时考虑几件事：路径本身的约束（起点、终点、途经点在哪）、时间上的约束（通常不是直接给时间，而是通过速度和加速度间接体现）、机器人能不能真的到达某个姿态，以及会不会撞到别的东西。

规划好的轨迹要变成机器人真正的运动，中间要经过几道工序，称为面向指令段的轨迹控制（satzorientierten Bahnsteuerung）。大致分四步：
\begin{enumerate}
    \item 为指令段做准备（Satzvorbereitung）把编程时给出的几何数据和运动学数据整理成数学函数
    \item 轨迹插补（Bahninterpolation）计算出轨迹上一个个具体的点
    \item 坐标变换（Koordinatentransformation）接着把这些点从直角坐标系（x、y、z）转换成机器人每个关节该转的角度值
    \item 位置控制（Lageregelung）最后把这些角度值作为目标值，交给位置控制器去驱动电机实际执行。
\end{enumerate}

机器人的运动方式主要有三种。
\begin{itemize}
    \item 点位控制（PTP，Point to Point）：只规定起点和终点，每个关节各自独立地从起点转到终点，中间走的具体路径形状是不确定的，各轴可以同步也可以异步动作，优点是简单快速，常用于不要求路径形状的搬运任务。
    \item 第二种是多点控制（MP）：通过预先采样、记录一系列密集的路径点来描述一条复杂曲线，常用示教/回放的方式编程，实际执行时其实还是一段段PTP运动拼起来的。
    \item 第三种是连续轨迹控制（CP，Continuous Path）：整条路径的位置和姿态在全程都被精确规定，常见的插补方式有直线、圆弧、样条曲线，其中直线轨迹最常用，比如装配这类需要精确路径的场合。这些插补方式如图 \ref{fig:interpolation} 所示。
\end{itemize}

轨迹生成（Bahngenerierung）是把轨迹规划的结果真正落实为可执行的技术方案。做法是先用一个"轨迹参数"（比如弧长）把整条路径写成一个纯几何函数，这样一来，路径的形状就和走这条路径用多快的速度完全脱钩了。我们先只关心"路径长什么样"，再单独考虑"沿着这条路径要走多快"。之后再通过给定一个速度曲线或加速度曲线，把时间信息叠加回几何路径上，这样机器人才知道每个时刻该在轨迹的哪个位置、以多快速度经过。这种"先几何、后时间"的分离处理方式，让同一条路径可以配上不同的速度节奏，灵活性更高。

实际生产中，机器人经常要连续经过好几段轨迹，如果每段之间都要完全停下来再启动，效率很低、也容易造成冲击。解决办法是越点运动（Überschleifen）：在两段轨迹的连接处插入一段样条曲线，让路径在几何上平滑过渡，不必真正停下来。这样做的好处是运动更连贯、对电机和机械结构的冲击更小、还能提高运行速度、缩短节拍时间；代价是路径会因此产生一点点偏差，存在轻微的碰撞风险，需要在效率和精度之间做权衡。


\subsection{编程方法}

\subsubsection{在线编程}

在线编程的特点是直接在真实机器人上进行示教，主要有两种做法。
\begin{itemize}
    \item 示教编程（Teach-In）：如图 \ref{fig:teachin} 所示，操作人员用一个操作手柄，把机器人依次移动到任务需要的几个关键位置，每到一个位置就把该点的坐标连同相关参数（比如用哪种插补方式、走多快）一起存下来；正式运行程序时，机器人就按顺序依次开到这些存好的点，并套用当时记录的参数。
    \item 引导编程（Playback）：如图 \ref{fig:playback} 所示，不是一个点一个点地示教，而是直接"拉着"机器人的手走完整个动作，比如靠装在末端执行器上的力矩传感器感知人手的推力，或者靠一个运动学替代模型来跟随人的动作，机器人会把整个连续的运动过程记录下来，之后原样重放。
\end{itemize}
这两种方式的共同优点是直观、不需要专业编程知识，缺点是要占用真实机器人的时间，示教期间机器人没法干别的活。

离线编程也是有两种做法：
\begin{itemize}
    \item 文本编程：直接用文字代码写程序，因为只需要一个编辑器，投入成本很低；不过问题在于几乎每个机器人厂商都有自己的一套编程语言，彼此互不兼容，业内也尝试过推出通用标准（比如IRL、IRDATA这类语言），但一直没有真正普及开。
    \item 基于仿真的编程：先在电脑里把整个加工单元（工作台、零件、机器人等）建模出来，规划好机器人大致怎么运作，再通过设置一系列"途经姿态"（Via-Pose）来编写机器人的运动路径。这种方式还能顺带做一些额外的事情，比如提前检查路径会不会发生碰撞、协调多台机器人协同工作、以及把编好的程序直接导出给真实机器人使用。
\end{itemize}

仿真模型里规划的路径搬到真实产线上执行时，因为设备安装误差、零件实际位置和仿真设想的不完全一致等原因，机器人实际走的位置和姿态往往会和理论值有偏差（叫作姿态误差）。为了解决这个问题，通常先在仿真环境里把整套系统规划出来，然后把真实设备搭建起来，接着对真实产线进行实测标定（把现场的真实坐标和仿真里的坐标对应起来），最后根据标定结果反过来修正仿真模型，或者给机器人的原始轨迹加一个"偏移量"，让仿真规划出来的路径在真实世界里也能精确复现。


\subsubsection{混合编程}

在线和离线各有短板。在线示教直观但占用产线时间，离线编程不占产线但编出来的程序和现实容易有偏差。混合编程就是把两者结合起来，先用示教在真实机器人上快速确定出几个关键位置，锚定住任务的大致框架，然后再用离线的方式去补充和精细化：一种做法是用示教编程定好关键点后，再用文本代码把中间的逻辑、参数补全；另一种做法是用示教编程定好关键点后，再放到仿真环境里做进一步的路径优化和碰撞检查。这样既保留了示教"所见即所得"、贴近真实情况的优点，又能用离线手段做更精细的编辑和验证，减少了纯离线编程常见的仿真与现实偏差问题。


\subsection{智能化融入}
\label{subsec:intelligent}

前面几节讲的都是机器人本身，它长什么样、怎么动、怎么编程。这一节换了个角度，讲的是怎么把机器人聪明地安排进一条有人参与的生产线，让人和机器人各自发挥所长、协同完成任务。

\paragraph{示例：飞机隔框铆接}

如图 \ref{fig:nietprozess} 所示，原来的做法是两名工人手持铆枪和顶把，把大量铆钉一颗颗打进隔框，把它和机身段连接起来。这个工作又累又不符合人体工学，因为它经常需要将手臂举过头顶作业，铆钉数量又多，是个很适合重新设计、引入自动化辅助的场景。

\begin{figure}[htbp]
  \centering
  \includegraphics[width=1\textwidth]{nietprozess.png}
  \caption{飞机隔框铆接的原始方法}
  \label{fig:nietprozess}
\end{figure}

要把人和机器人智能地组合到一条产线里，大致分六步：
\begin{enumerate}
    \item 流程规划与方案设计，明确任务该分给人还是机器人
    \item 建一个虚拟模型，把产品、工艺、设备信息都参数化地描述出来
    \item 做产线配置，把规划好的方案在现实中搭建起来并标定
    \item 设计，让工人能方便地了解和调整系统
    \item 实际操作运行
    \item 工艺执行
\end{enumerate}
这六步环环相扣，前一步的结果是后一步的输入。接下来将详细解释每一个步骤是如何实现的。

\paragraph{第一步：流程规划与方案设计}

方案设计的核心是能力匹配（Mapping）：先梳理出这项任务实际需要哪些能力，再对比人和机器人各自能提供哪些能力，把两者匹配起来，形成几种备选方案。总体来看，人的优势在于灵活、能到处移动、有认知判断能力、能自主安排工作；短板是对工艺的把控不够精确、容易受人体工学限制、还可能因为操作失误、疲劳导致质量不稳定。机器人恰好相反：能严格按照设定路径精确移动、可靠地重复执行单调任务、结果一致性好；短板是产品设计必须迁就自动化要求、遇到公差偏差需要额外的补偿手段、也不像人一样灵活应变。

放到铆接案例里，工人负责铆接任务里需要灵活操作、经验判断的部分（准备工位、装铆钉、操作铆枪），机器人则负责单调但需要稳定输出力的部分（拿着顶把在隔框内侧提供反作用力）——外面的人操作铆枪，里面的机器人稳稳地"顶住"，两者配合完成铆接。

\paragraph{第二步：虚拟模型}

有了分工方案后，先不急着上真实设备，而是搭建一个虚拟模型，把产品、工艺流程和所用设备的信息都参数化地记录进去。模型的详细程度越高，就越能提前在电脑里对方案做分析、验证和优化，减少后续返工的风险。

\paragraph{第三步：产线配置}

把实际需要的设备搭建、摆放到位，再通过测量确定它们真实的位置和朝向（叫作"标定"），并把这些实测数据反馈回虚拟模型里，让虚拟模型和现实情况对齐。之后机器人的实际控制就可以基于这个校准过的虚拟模型来进行。

标定本身还可以分三个层级，如图 \ref{fig:konfiguration} 所示：
\begin{figure}[htbp]
  \centering
  \includegraphics[width=0.8\textwidth]{konfiguration.png}
  \caption{标定的三个层级}
  \label{fig:konfiguration}
\end{figure}
\begin{itemize}
    \item \emph{全局标定（Globales Einmessen）}：确定大件设备（比如工作台）在空间中的整体位置；
    \item \emph{区域标定（Regionales Einmessen）}：修正某个工件本身摆放位置的偏差；
    \item \emph{局部标定（Lokales Einmessen）}：进一步测量工件上具体特征点（比如某个铆钉孔）的精确偏差。
\end{itemize}
层级越细，精度要求也越高。案例中就用到了区域标定：用线激光三角测量传感器识别隔框上的铆钉孔图案，据此计算出一个局部坐标系，用来修正真实工件和CAD模型之间的偏差，进而推算出其余铆钉孔的准确位置，供机器人后续铆接使用。

\paragraph{第四步：人机交互界面}

产线上的工人往往不懂机器人编程，但生产中经常需要根据新的产品变型或流程优化去调整机器人程序。解决办法是给工人提供直观的操作界面和仿真环境，让他们不需要专业编程知识也能修改任务，调整结果还会实时反馈给工人确认。人和系统之间的信息交流方式也可以多种多样：系统向人输出信息可以是视觉的（文字、图像、动画、指示灯）、听觉的（语音、提示音）、或触觉的（振动、力反馈）；人向系统输入指令则可以靠操作面板、语音、手势识别，或者靠定位追踪系统。此外还可以借助VR、AR、MR技术，让工人透过设备"看到"产品内部结构、下一步该去哪个加工点、机器人的运动轨迹等本来看不见的信息。

\paragraph{第五步和第六步：实际操作运行工艺执行}

系统运行起来后，工人应当能在生产过程中随时进行简单的干预，比如用智能手表或语音喊"机器人启动/停止"来控制流程推进到下一步，不需要复杂培训就能上手，也让工人对整个流程更有掌控感、更容易接受这套人机协作方式。
